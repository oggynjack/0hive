The problem

Every unofficial Gemini wrapper has the same failure mode.

Web sessions quietly expire. Copying cookies between machines gets flagged. And checking by hand means you only find out it's broken when something else fails downstream.

Sessions rot in ~7 days

Nothing refreshes a session you're not actively using, so it goes stale right when you need it.

Copied cookies get rejected

Google ties sensitive cookies to how and where they were captured. A plain export-and-replay often just doesn't authenticate.

One account, one point of failure

No fallback means every rate limit or hiccup becomes your outage.

How 0Hive fixes it

Pick the sync method that fits how you work.

Three independent ways to keep accounts alive — run one, or all three.

recommended CDP mode

Attach to your real browser

Reads whichever Google accounts are signed in to the browser you already use every day, over its DevTools port. Since it's genuinely your session, nothing looks automated.

Isolated profile

One dedicated login

Sign in once in a separate browser profile; a background keeper re-exports fresh cookies from it every 30 minutes, forever.

Extension

One click, every account

A browser extension that finds every signed-in account and sends it to your sync server, identified by email, on a timer.

What you get

One gateway. Every account you add.

OpenAI-compatible

Drop-in /v1/chat/completions and /v1/models — point your existing client at it.

Automatic failover

A stale or rate-limited account is skipped transparently; the next healthy one answers instead.

Live dashboard

Requests, tokens, latency, and per-account health, updating in real time. Fully responsive.

Built-in chat tester

Try it immediately with a live model list pulled from the server — never a hardcoded, outdated name.

Self-healing

No account ever gets manually re-logged-in on a deadline — the keeper refreshes it before it matters.

Quickstart

Running in under five minutes.

# clone and install
git clone https://github.com/oggynjack/0hive.git
cd 0hive
pip install -r requirements.txt
cp config.example.json config.json

# add a cookie file for one account, then:
python gemini_web2api.py
# call it like any OpenAI-compatible API
curl http://localhost:8081/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-auto",
    "messages": [{"role":"user","content":"hi"}]
  }'
Get started

Clone it. Run it. Never think about login again.
